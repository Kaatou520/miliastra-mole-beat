# 网页原型实现笔记

三个页面都是**单文件**：HTML + 内联 CSS + 内联 JS，没有构建、没有依赖、没有音频文件。
双击即可玩，扔到 GitHub Pages 上也一样。

| 文件 | 说明 |
|---|---|
| `web/index.html` | 主场景：打地鼠 + 商店（2.8k 行，91 KB） |
| `web/wheel.html` | 幸运转盘，独立窗口（760 行） |
| `web/slot.html` | 老虎机，独立窗口（880 行） |

## 结构约定

主场景只放打地鼠 + 商店。转盘和老虎机是**各自独立的窗口**，从主场景左上角卡片
用 `window.open` 打开；从主场景开出来的窗口点「返回」就 `window.close()`，
单独打开的话则跳回 `index.html`。以后加成就、抽卡、背包也照这个来：**一个新页面，一个入口**。

三页共用一份存档 `localStorage: dmsq.save.v1`（金币 / 武器 / 转盘记录 / 老虎机记录），
每边只写自己那几个字段，不会互相覆盖；回到主场景时自动同步余额。

## 美术风格（「光景」）

| 元素 | 做法 |
|---|---|
| 配色 | 浅天蓝底 `#bdefff` + 深靛蓝墨 `#070a7d` + 亮黄高亮 `#fff100` + 橙 `#ff7031` |
| 卡片 | 纸白 `#f7fcff` + 2~3px 靛蓝描边 + 位移硬阴影 `7px 8px 0 rgba(7,10,125,.16)`（不带模糊） |
| 字形 | 标题 / 数字用 Archivo Black，正文用 Outfit，中文走系统黑体 |
| 排印 | 小号英文 kicker（`GAME 02 / FORTUNE WHEEL`）+ 橙色圆点 + 细横线；标题带白色硬投影 |
| 质感 | 全屏一层 7% 的纸颗粒噪点（内联 SVG `feTurbulence`，无图片） |
| 边角 | 一律接近直角（2~3px 圆角），按钮按下去是「位移 + 阴影消失」 |

设计稿 1280×720，按窗口等比缩放；竖屏手机会提示旋转。

## 场景分层

```
远景   拱门 ×3 / 深色柱 ×4 / 垂幡 ×3 / 壁灯 ×4
中景   栏杆
近景   地砖地面（透视横线 + 中央亮光）
玩法   三排洞穴：r1 缩 0.78、r2 缩 0.89、r3 缩 1.00（近大远小）
HUD    左上 商店/转盘/老虎机/金币/武器等级 · 顶部 宝箱进度条 + 连击 · 右上 气泡 · 右下 音效/重开
```

### 视差背景

远景和近景两层循环横移：每层做一张 1280px 宽的「画面」，JS 克隆一份排到右边，
轨道整体 `translateX(0 → -1280px)`，所以接缝无缝。

| 层 | 内容 | 走完一屏 | 速度 | 附加 |
|---|---|---|---|---|
| 远景 | 拱门 + 壁灯 | 84 s | ≈15 px/s | ±8px 上下浮动 |
| 近景 | 柱子 + 竖幡 | 52 s | ≈25 px/s | ∓5px 上下浮动 |

其余局部动画叠在漂移之上：天空光晕 20s、拱门 9s 呼吸、柱子 7.5s 扫光、壁灯 3.4s、
地面光斑 13s、云影 ×3 分别 34 / 46 / 58s 横穿。

## 打击特效

只作用在命中点周围 90～280px，不铺满全屏：

| 层 | 实现 |
|---|---|
| 白爆点 | 命中点炸开一个白→彩色的径向光点 |
| 冲击圆环 | 1～2 圈粗描边圆环向外扩 |
| 爆散色块 | 11～16 个糖果色方块 / 圆片（岩属性 16～20 个），4px 描边，飞出后消失 |
| 四角星 | 2～4 颗星形闪光 |
| 史莱姆被打飞 | 复制贴图旋转飞出屏幕（向上为主，随机偏角） |
| 涂鸦字 | 白字 + 深色粗描边 + 品红 / 青错位，随机词库 |

**每次命中都不一样**：`mulberry32` 以「时间戳 ⊕ 随机数」为种子，同一次命中内的所有随机量
（配色、色块数量 / 大小 / 形状 / 方向、圆环粗细、星星位置）都由这一个种子驱动。
配色从 8 色糖果色里随机抽：`#ff2e88 #ffd23f #2ee6f6 #8b5cf6 #ff7a3d #4ade80 #fff #ff5aa0`。
所有元素 300～720ms 内回收。

这套特效后来被 1:1 搬进了千星（改成运行时实例 + 每帧算位置），见
[`docs/miliastra-handoff.md`](miliastra-handoff.md)。

## 音效

全部 WebAudio 现场合成，没有外部音源，分层细节见 [`design.md`](design.md#音效设计)。
要点是一条母线 `Gain → DynamicsCompressor`（−18dB / ratio 8 / attack 3ms，主增益 1.25），
多声部同时响也不爆、不糊。

## 页面里的可调参数

| 位置 | 变量 | 作用 |
|---|---|---|
| `index.html` | `ASSETS` | 贴图表（`imageId` ↔ 文件名），换素材只改这里 |
| `index.html` | `CFG` | 刷新间隔 `spawnGap`、是否打空断连击等 |
| `index.html` | `BONUS` | BONUS 存活时长 / 命中区间 / 推镜步长与上限 |
| `index.html` | `MILESTONES` | 连击里程碑与额外金币 |
| `wheel.html` | `WHEEL.pays` | 红 / 黑 / 绿赔率（绿改 30 就是平衡水位） |
| `slot.html` | `SLOT.stepMs` | 老虎机每格过窗时间（默认 100ms） |

## 已知取舍

- 老虎机的滚轮在千星里不是真滚动（窗口没有裁剪），但网页原型是真的连续滚动
- 商店只有武器升级，没有外观 / 装饰；成就与多人模式没做
