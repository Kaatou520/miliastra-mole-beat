# 千星版本：怎么把它跑起来

这个目录里只有两样东西：

| 文件 | 说明 |
|---|---|
| `mole-beat-main.gia` | 主场景的 UI 整合包（控件树 + 9 个客户端控件模板），347 KB |
| `../lua/main.lua` | 玩法脚本，约 2 千行 / 65 KB，挂在「容器节点」上 |

界面是用一个自建的 UI 模拟器生成存档、再导出的，所以 `.gia` 里就是**最终控件树**，
不是需要你在编辑器里一步步搭的教程。控件规模：71 个控件 + 9 个客户端控件模板。

## 导入流程

1. 千星编辑器里 **导入 GIA 整合包** → 选 `miliastra/mole-beat-main.gia`
2. 转存到自己的工程，加入「自定义布局」
3. 绑到职业默认布局（舞台画布建议 `mobile-16-9`，1280×720）
4. **脚本映射**：把 `lua/main.lua` 挂到根「容器节点」上
5. 进试玩，先看没报错、9 个洞能出史莱姆

## 它做了什么（不靠编辑器也能看懂的部分）

- **打击特效是运行时粒子**：9 个客户端控件模板（fx块 / fx圆块 / fx环 / fx星 / fx爆点 / fx涂鸦 / fx数 /
  fx史莱姆 / fx彩虹）在命中时 `game.InstantiateClientUIControl` 出来，每帧算位置、缩放、旋转、透明度，
  寿命到点销毁；透明度量化成 6 档，避免每帧重建图元
- **推镜（camZoom）**：千星没有相机，直接缩放挂载控件（全屏 stretch 容器）就等价于给网页
  `.screen` 加 `scale`——场景树是父子嵌套，点击会经父矩阵逆变换，不会错位
- **画布适配**：背景铺满（2600 宽）→ 页面容器改 stretch → `OnStart` 里按 `GetUICanvasSize()`
  算四边余量，把 HUD 逐个贴边；19.5:9 与 4:3 都不会露底色
- **模板索引自检**：真机上模板索引可能被重排，启动时按子控件名 / 图元特征反认 9 个模板再用
- **素材兜底**：取不到元件贴图时按 id 换图元，图标用三角形 / 圆 / 环重绘，不会显示「?」

实现细节、踩过的坑、和网页的差异都写在 [`../docs/miliastra-handoff.md`](../docs/miliastra-handoff.md)。

## 注意

- `.gia` 里引用的是**千星元件库的 `imageId`**（水史莱姆 30002006 等），不含贴图文件本身
- 成就相关的服务器信号要在「服务器信号管理器」里自己定义，见
  [`../docs/publish-checklist.md`](../docs/publish-checklist.md)
